# Portafolio Web Personal

¡Bienvenido a mi portafolio! Este proyecto es una página web estática desarrollada para mostrar mis habilidades como desarrollador web junior, así como los proyectos en los que he trabajado.

🔗 **[Visita mi portafolio en vivo aquí](https://jhonylopez0507-cpu.github.io/web_project_portfolio_es/)**

## Descripción del proyecto

Este sitio web fue diseñado y maquetado desde cero basándose en un diseño profesional de Figma. El objetivo principal es demostrar el dominio de la estructura semántica de HTML y las técnicas modernas de diseño con CSS, garantizando una experiencia visual impecable y adaptable a cualquier dispositivo (Responsive Design).

## Características principales

- **Diseño Responsivo:** La página se adapta perfectamente a pantallas de escritorio, tabletas y teléfonos móviles utilizando Media Queries.
- **Maquetación Moderna:** Uso avanzado de Flexbox y CSS Grid para organizar las tarjetas de proyectos y la sección de habilidades.
- **Estructura Semántica:** Código HTML limpio y accesible que facilita la lectura tanto para otros desarrolladores como para los navegadores.
- **Metodología BEM:** Clases de CSS organizadas siguiendo la convención de bloques, elementos y modificadores (Block, Element, Modifier) para un código escalable.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Figma (Exportación de recursos y lectura de diseño)
